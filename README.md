# COS 201 — Computer Programming I
## Week 3 Java Programs

This repository contains three beginner-level Java programs:

1. `SimpleCalculator.java` — performs addition, subtraction, multiplication, and division.
2. `AverageCalculator.java` — calculates the average of a user-entered set of numbers.
3. `ItemCost.java` — calculates total item cost by multiplying unit cost by quantity.

## Requirements

- Java Development Kit (JDK) installed
- A terminal or command prompt

## How to compile

Open a terminal in the folder containing the Java files and run:

```bash
javac SimpleCalculator.java AverageCalculator.java ItemCost.java
```

## How to run

Run each program separately:

```bash
java SimpleCalculator
java AverageCalculator
java ItemCost
```

Follow the prompts shown by the program.

## Example tests

### SimpleCalculator
- First number: `8`
- Operator: `*`
- Second number: `3`
- Expected result: `24.0`

### AverageCalculator
- Number count: `3`
- Numbers: `10`, `20`, `30`
- Expected average: `20.0`

### ItemCost
- Item name: `Pen`
- Unit cost: `150`
- Quantity: `4`
- Expected total cost: `600.00`
